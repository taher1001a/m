# 📊 نظام إدارة الديون والمخزون (Debt & Inventory Management)

تطبيق ويب متكامل لإدارة الديون والمخزون، متوافق مع الهواتف والحواسيب، ويدعم اللغة العربية بالكامل (RTL).

---

## ✨ المميزات المنفذة

### 1️⃣ نظام إدارة الديون
- إضافة / تسديد / تعديل الديون (جزئي أو كلي)
- **الدمج التلقائي**: عند إدخال اسم عميل موجود يتم دمج الدين تلقائياً في حسابه
- كشف حساب تفصيلي لكل عميل (سجل إضافة/تسديد/تعديل)
- طباعة وصل دين / كشف حساب (متوافق مع الطابعات الحرارية و A4/A5)
- تصدير PDF
- **مشاركة عبر واتساب** بنص منسّق (المتبقي، المنتجات، التاريخ)
- إحصائيات فورية (إجمالي الديون، المسدد، تصنيف العملاء)

### 2️⃣ نظام إدارة المخزون
- إضافة منتجات (يدوياً أو بالباركود)
- **خصم تلقائي** من المخزون عند تسجيل دين/بيع يحتوي منتج
- تنبيهات عند وصول المنتج للحد الأدنى
- تعديل الأسعار والكميات

### 3️⃣ الفواتير
- إنشاء فواتير (دين / بيع نقدي)
- طباعة / PDF / مشاركة واتساب

### 4️⃣ الأمان والنسخ الاحتياطي
- واجهة تسجيل دخول Google (جاهزة لربط Firebase)
- وضع تجريبي لاختبار التطبيق فوراً
- تصدير/استيراد نسخة احتياطية JSON
- بنية جاهزة لربط Firebase للمزامنة السحابية التلقائية

## 🌐 التشغيل على GitHub Pages (مهم لتسجيل الدخول بجوجل)

عند رفع التطبيق على GitHub Pages، لتسجيل الدخول بجوجل يجب ضبط **Firebase** بشكل صحيح:

### الخطوة 1: أضف نطاق GitHub Pages إلى النطاقات المسموحة في Firebase
1. اذهب إلى [Firebase Console](https://console.firebase.google.com) → مشروعك `deon-8d7fa`.
2. من القائمة → **Authentication** → تبويب **Settings**.
3. في قسم **Authorized domains** (النطاقات المسموحة) اضغط **Add domain**.
4. أضف نطاقك على GitHub Pages. مثال:
   - إن كان اسم مستخدمك GitHub هو `username` والتطبيق في مستودع `myapp`:
     ```
     username.github.io
     ```
   - وإن كان التطبيق في صفحة فرعية (Project Pages):
     ```
     username.github.io
     ```
   (أضِف `*.github.io` أيضاً إن أمكن لتغطية كل النطاقات الفرعية)
5. احفظ.

### الخطوة 2: تأكد من تفعيل Google Authentication
1. Firebase Console → **Authentication** → **Sign-in method**.
2. فعّل **Google**.
3. أضف بريدك الإلكتروني في **Support email** (إلزامي).
4. احفظ.

### الخطوة 3: أضف نطاق التشغيل في OAuth consent
1. Firebase Console → **Authentication** → **Settings** → قسم **Authorized domains**.
2. أضف `username.github.io` (كما في الخطوة 1) — هذا يسمح لـ OAuth بالعمل.

### الخطوة 4: كيف يعمل تسجيل الدخول الآن في الكود
بعد هذه التعديلات، يعمل تسجيل الدخول تلقائياً بالترتيب التالي:
1. **Popup** (نافذة منبثقة) — الأسرع.
2. إن فُشلت (حجب النوافذ) → **Redirect** (تحويل الصفحة) وهو الأكثر موثوقية على GitHub Pages.
3. إن تعذر كلاهما → الدخول بالوضع التجريبي.

## 🔗 ربط Firebase (النسخة الكاملة)

لتفعيل تسجيل الدخول الحقيقي بجوجل والنسخ الاحتياطي السحابي التلقائي:

1. أنشئ مشروعاً في [Firebase Console](https://console.firebase.google.com)
2. فعّل **Authentication** → طريقة **Google**
3. فعّل **Firestore Database**
4. انسخ إعدادات التطبيق (Config) وعدّل **`js/auth.js`**:

```js
firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    authDomain: "YOUR_PROJECT.firebaseapp.com",
    projectId: "YOUR_PROJECT_ID",
    storageBucket: "YOUR_PROJECT.appspot.com",
    messagingSenderId: "YOUR_SENDER_ID",
    appId: "YOUR_APP_ID"
}
```

5. بعدها يتصل التطبيق تلقائياً ويصبح النسخ الاحتياطي سحابياً وتلقائياً.

## 🛠️ التقنيات

- **الواجهة**: HTML5 + CSS3 + JavaScript (Vanilla)
- **قاعدة البيانات**: محلياً localStorage، وجاهزة لـ Firebase/Firestore
- **المصادقة**: Firebase Authentication (Google)
- **PDF**: html2pdf.js / jsPDF + طباعة مباشرة
- **واتساب**: روابط `wa.me`
- **الباركود**: Web Barcode Detection API + قارئ خارجي
